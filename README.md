# Anacondaz — сайт (первый слой)

## Запуск
```
npm install
npm run dev
```

## Структура — многостраничный сайт (React Router)
Раньше всё было одним длинным лендингом. Теперь — реальные страницы,
общие Nav/Footer, контент рендерится только для текущего маршрута:

- `/` — Home: Hero + короткий Origin-тизер + карточки-ссылки на остальные
  страницы (`src/pages/HomePage.jsx`)
- `/about` — Collabs + DIY/краудфандинг (`AboutPage.jsx`)
- `/discography` — дискография, marquee, Spotify-embeds (`DiscographyPage.jsx`)
- `/tours` — афиша (`ToursPage.jsx`)
- `/booking` — букинг + партнёры (`BookingPage.jsx`)
- `/contacts` — соцсети/контакты (`ContactsPage.jsx`)
- `*` — 404 (`NotFoundPage.jsx`)

Контент секций живёт в `src/sections/*` (переиспользуемые блоки), страницы в
`src/pages/*` их компонуют. `Nav` и `SiteFooter` — глобальные, живут в
`App.jsx` вне `<Routes>`. При смене маршрута скролл сбрасывается наверх и
`ScrollTrigger.refresh()` пересчитывает позиции под новый DOM
(`RouteChangeHandler` в `App.jsx`).

⚠️ Деплой на Vercel: добавлен `vercel.json` с rewrite на `index.html` —
без него прямые ссылки на `/tours` и т.п. отдавали бы 404 при обновлении
страницы (SPA-роутинг).

## Что уже собрано
- Vite + React 19 + Tailwind v4 (design tokens в `src/index.css` через `@theme`)
- RU/EN через react-i18next (`src/i18n/locales/*.json`), переключатель в шапке
- React Router: Nav/Footer глобальные, страницы — `src/pages/*`
- Секции: Hero (text-scramble), Origin, Discography (marquee + reveal/stagger),
  Collabs, Tours, Booking, Partners, DIY/краудфандинг, Contacts
- GSAP/ScrollTrigger хореография (parallax, scroll-scrub, marquee по
  скорости скролла), кастомный курсор, прелоадер, Lenis smooth scroll —
  всё уважает prefers-reduced-motion
- Данные (дискография/туры/партнёры/соцсети) вынесены в src/lib/content.js,
  тексты — в src/i18n/locales/

## Редизайн по вашему фидбэку
- **Фон**: чистый чёрный `#0A0A0A` вместо тёплого коричнево-чёрного — жёстче
  и контрастнее
- **Акцент**: точный золотой цвет из вашего лого `#FDB813` (был приблизительный
  `#D6A419`)
- **Шрифт заголовков**: Anton вместо Archivo Black — плотнее, ударнее,
  плакатно-панковский, а не обобщённый grotesk
- **Текстура**: halftone-точки (растровая печать, эстетика самиздат-флаеров)
  вместо мягкого грейна — острее, не "муть на фоне"
- **Диагональные разрезы** между hero и следующим блоком — графический приём
  вместо ровных линий
- **Hero теперь слайдер** 1920×1080 вместо текстовой фразы (src/components/
  HeroSlider.jsx). Реальных фото ещё нет — слайды генеративные (halftone +
  диагонали в золоте/чёрном, в стилистике сайта), с явной подписью
  "PHOTO SLOT — заменить на реальное фото". Как пришлёте фото — кладёте файлы
  в public/hero/ и прописываете пути в src/lib/content.js → heroSlides
- **Spotify-плеер с превью**: два официальных iframe-embed'а (не самодел) —
  featured-блок с альбомом «Ночь с астраханцем» и embed всего каталога артиста
  (id подтверждены напрямую в Spotify: артист 150K слушателей,
  open.spotify.com/artist/2e7yDxnK4osy7nKhnqrOFM)

## Готово в предыдущей итерации
- Логотип подключён (public/logo.svg, favicon), акцентный цвет темы подстроен
  под его золотой оттенок (#FDB813 → --color-ochre)
- Пресс-кит/райдер для Booking: public/anacondaz-presskit.pdf, сгенерирован
  из реальных фактов дискографии/коллабораций, PDF зашифрован паролем **1111**
  (pypdf `.encrypt`, а не просто скрытая ссылка — файл не откроется без пароля
  даже если ссылку найдут напрямую)
- В блоке Booking — форма с паролем перед кнопкой скачивания. Важно: это
  клиентская проверка (пароль виден в исходном JS), она отсекает случайных
  посетителей, но не защищает от того, кто откроет devtools. Реальная защита —
  сам PDF, он зашифрован. Когда подключим Supabase, вынесем проверку на бэкенд
  и уберём пароль из клиентского кода
